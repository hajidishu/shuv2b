# 用户

## 筛选与批量操作

在「用户管理」添加过滤条件，可组合邮箱、余额、佣金余额、套餐、权限组、状态等字段。金额支持比较，界面按元显示，API 金额使用整数分。

批量操作前核对范围：勾选用户、当前页与全部筛选结果不同；无筛选时可能覆盖全站。CSV 按筛选范围导出。

## 编辑用户

可修改套餐、到期时间、流量、设备数、限速、余额、佣金等权益。密码留空保留旧密码；封禁、角色变更和会话撤销按当前数据库状态生效。

普通节点按套餐权限组授权；[人工排查节点](../features/leak-probe)按任务名单授权。[订阅审计](../features/subscription-audit)可按邮箱查询拉取行为，并复制当前订阅链接。

## 常见问题

**删除还是封禁？** 封禁适合保留数据并停用账号。删除会清理关联订单、邀请码、工单等数据，不会向支付平台退款；财务台账和历史审计按各自规则保留。

**员工接口为何不可用？** 本分支已关闭未完成的 Staff API，历史员工字段可能仍保留；管理员 API 不受影响。
