# 订阅与套餐

## 创建套餐

在「订阅管理」填写名称、介绍、各周期价格、流量、设备数、权限组、重置方式、最大用户量和限速。

| 类型 | 权益 |
| --- | --- |
| 月付至三年付 | 延长对应期限，按重置设置恢复流量 |
| 一次性 / 按量 | 无周期到期时间，受流量配额限制 |
| 重置包 | 重置当前已用流量 |

销售与续费开关独立。修改套餐默认值不会必然覆盖已有用户权益；需同步时核对「强制更新用户」的范围。

## 续费、更换与折抵

有效期内购买相同套餐通常为续费，不同套餐为更换。过期重购、重置包、切换套餐类型及新购 / 续费 / 更换事件设置会影响流量重置；符合条件的追加按量购买可累计剩余额度。

在「系统配置 → 订阅」开启折抵。按量套餐按剩余流量比例计算有效购买价值；周期套餐同时考虑剩余时间、流量和多月周期。折抵不超过符合条件的已付价值，以结账明细为准，不代表原渠道退款。

## 流量重置方式

| 值 | 规则 |
| --- | --- |
| `0` | 每月 1 日 |
| `1` | 按到期日的日号每月重置 |
| `2` | 不自动重置 |
| `3` | 每年 1 月 1 日 |
| `4` | 按到期日期的月日每年重置 |

套餐留空时继承全局设置。自动重置要求账户有效且每日调度正常；按到期日重置与最后下单日不同。

## 订阅链接

「系统配置 → 订阅」可选永久、一次性或限时链接。从用户中心或管理员详情复制链接，确保凭据符合当前模式。[订阅审计](../features/subscription-audit)保留历史请求 token，并单独提供当前链接。

## 常见问题

**支付后一直开通中？** 检查通知、收款台账和 `order_handle` 队列，见[支付](./payment)。

**续费后流量何时重置？** 查看用户到期日、套餐重置方式及事件设置，不能只按付款日期推断。
