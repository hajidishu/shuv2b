# 邮件

## 配置发送

1. 在「系统配置 → 邮件」填写服务商提供的 SMTP 主机、端口、账号、密码、加密方式和发件地址。
2. 发送测试邮件，确认实际收到。
3. 确保 `send_email`、`send_email_mass` 队列运行；更改配置后让常驻消费者重新加载。

## 自定义模板

在 `resources/views/mail` 中复制现有主题，修改 Blade 文件，再在后台选择该主题。自定义文件需备份，避免更新覆盖。

| 模板 | 用途 |
| --- | --- |
| `notify` | 自定义通知 |
| `remindExpire` | 到期提醒 |
| `remindTraffic` | 流量提醒 |
| `verify` | 邮箱验证码 |

## 常见问题

**测试成功但业务邮件未收到？** 检查任务是否入队、消费者和失败任务，再检查 SMTP 日志、发件域名验证、出站连接及垃圾箱。
