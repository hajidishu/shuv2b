# 邀请返佣

## 设置返佣

在「系统配置 → 邀请&佣金」设置全局比例、首次或持续返佣、自动审核与提现。用户专属比例和返佣方式可覆盖全局条件，订单详情显示实际佣金。

开启自动审核后，符合条件的订单满三天进入审核流程；`check:commission` 每 15 分钟执行。审核与发放依赖[调度器及队列](../deploy/queues)。管理员也可在订单中确认或驳回佣金。

提现和佣金转入可用余额分别按站点设置处理。

## 三级分销

各级比例分配的是订单佣金池。例如佣金池为 10 元，三层比例为 50% / 30% / 20%，对应 5 / 3 / 2 元。缺少上级、取整或不满足条件时，以佣金日志为准。

## 常见问题

**佣金没有增加？** 依次检查订单及佣金状态、邀请关系、用户专属设置、确认期和任务日志。重试前先核对已发记录，避免手工重复加款。
