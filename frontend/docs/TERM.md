# 术语

| 术语 | 含义 |
| --- | --- |
| 用户前端 | 用户登录、购买、获取订阅与提交工单的网页 |
| 管理员前端 | 管理用户、节点、订单及配置的网页，源码在 `frontend/admin` |
| 面板后端 | 处理 API、数据库、订阅生成、支付及队列的 PHP 应用 |
| 节点服务端 | 运行代理、拉取用户并上报流量的节点程序 |
| 客户端 | 用户设备上的连接软件 |
| 套餐 | 流量、期限、权限组、限速等权益 |
| 订阅链接 | 客户端拉取节点配置的 URL，凭据不同于登录 JWT |
| 权限组 | 关联套餐用户与普通节点的访问范围 |
| Horizon | Redis 队列管理进程，需守护运行 |
| 调度器 | 每分钟执行 `php artisan schedule:run`，触发定时任务 |
| 支付通知 | 支付平台向后端发送收款结果，后端验签并结算 |
| 支付回跳 | 浏览器返回前端页面，不代表已确认收款 |
| 订阅审计 | 记录订阅拉取请求，不记录用户访问互联网的内容 |
